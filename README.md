Tarjeta digital animada (HTML, CSS y JavaScript, sin dependencias).

## Contenido
```
index.html        la tarjeta completa
foto.jpg          foto de perfil
proyectos/        videos e imágenes del carrusel
```

## Publicarla con GitHub Pages
1. Sube todo el contenido de esta carpeta a un repositorio de GitHub.
2. Settings → Pages → Branch: `main` y carpeta `/ (root)` → Save.
3. En un par de minutos estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Editar tus datos
Abre `index.html` y busca el bloque `DATA` al inicio del `<script>`:
nombre, cargo, correo, teléfono, redes sociales y proyectos.

- **Agregar una imagen a un proyecto:** guárdala en `proyectos/` y escribe su ruta en `image`.
- **Agregar un enlace:** escríbelo en `url` del proyecto.
- **Más videos:** agrégalos a la lista `videos` (src, poster, label).
